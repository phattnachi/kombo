# KOMBO! by SOYA GAMES

8×8 Portrait Combo & FEVER Block Puzzle built with **Godot 4.7.2**.

## Modes
- **Classic:** Endless 8×8 board with HOLD / STASH vault, `×2`/`×3` multiplier tiles, Bomb & Lightning specials, and 2× FEVER mode.
- **Daily Challenge:** Worldwide deterministic daily board & identical block sequence (3 tries/day, streak tracker, clipboard share).
- **20-Turn Sprint:** 60 placements (`20 × 3` trays) high-score rush.
- **Gem Hunt:** Stage-based Crystal, Padlock, and 2-HP Ice target clearing with stage select & escalating score multipliers.

## Features
- Auto-save & seamless resume across all 4 modes
- One-handed portrait controls (mouse & touch)
- Second Chance Revive (`1×` per run) & End-of-Run `×2 Coins` ad-ready helper system (`AdBridge`)
- Procedural 44.1 kHz stereo rising-pitch synth SFX + adaptive BGM
- Ready for **Web (HTML5 PWA)** and **Android APK** (`com.soyagames.kombo`)
